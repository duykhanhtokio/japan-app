# 建設 学習確認テスト — 10回・各40問

既存の第1〜55週の日本語教材に基づく独自問題です。各問で最も適切なものを一つ選んでください。時間制限と合格基準は設けていません。

385の学習回を参照しますが、全段落の全知識を評価したという意味ではありません。専門家・日本語母語話者の審査前です。

## 建設学習確認テスト 第1回

### 問1
組立班の作業員が棚を組み終えたが、職長の確認はまだである。次の班への受渡しを説明する文として、役割と進捗を正しく分けているものを選びなさい。

1. 経験者の助言を受ければ、指定された確認先への連絡を省ける。
2. 組立ての終了と職長の確認待ちを分け、受渡し時刻は職長に確かめる。
3. 作業員の組立て終了を、職長による確認の完了として伝える。
4. 元請は会社の立場なので、職長という人の役割は現場に存在しない。

### 問2
初日の集合場所は聞き取れたが、時刻は聞き取れなかった。自己紹介を終えた人が続ける発言として、情報不足を最も具体的に示すものはどれか。

1. 「何も分かりません」とだけ言い、分かった場所も伝えない。
2. 「場所は分かりました。集合時刻をもう一度教えてください」
3. 「ご安全にと言ったので、時刻の連絡も済みました」
4. 「自己紹介は済んだので、集合についても確認済みです」

### 問3
全体朝礼で設備班の搬入と内装班の作業が同じ午前・同じ場所と分かった。全体朝礼と職種別朝礼の関係をどう捉えるか。

1. 朝礼を終えるあいさつは、両班の同時作業を認める許可になる。
2. 全体朝礼に出席した以上、内装班の詳しい予定確認は不要である。
3. 全体で知った重なりを班の責任者へ示し、職種別で詳しい条件の調整につなげる。
4. 他職種の搬入は自分の仕事でないので、班の話合いには持ち込まない。

### 問4
KYシートに「昨日は隣の班がいた。今日もいると思う。自分は搬入時間の変更を提案した」とある。記録を読み直した評価として適切なのはどれか。

1. 昨日の観察、今日の推測、未決定の提案を分ける必要がある。
2. 提案を記録した時点で、搬入時間の変更は決定した指示になる。
3. シートが存在すれば、危険の検討や対策の実施も全て完了している。
4. 昨日の観察があれば、今日の隣接作業も確認した事実になる。

### 問5
建設経験のある人が初めてCCUSに登録する。「全員、登録後に一律三年待たなければ上位評価へ進めない」という説明を検討する。教材に合う結論はどれか。

1. 経験が長い本人の申告だけで金カードの取得が決まる。
2. CCUSレベル2のカードを持てば、特定技能2号の在留条件も満たす。
3. 初登録者の経験は全員同じなので、必ず白カードから三年待つ。
4. 条件を満たせば登録と能力評価の同時申込があり、経歴証明等も必要になる。

### 問6
搬入が午前から午後へ変更され、二階という場所は変わらない。午後に二階を使う班へつなぐ情報として、最も欠落が少ないものを選びなさい。

1. 聞き取れない返事でも、一人から返事があれば全班へ伝達済みとする。
2. 「全て変更」とだけ伝え、場所も変わった扱いにする。
3. 先輩が他現場で使った順番へ、自分だけで内装予定を変更する。
4. 元は午前、変更後は午後、場所は二階のままで、午後の内装予定と重なることを職長へ伝える。

### 問7
金色のCCUSカードを持つ応援者が現場へ来た。所属会社の欄と本日の指示先の欄を記入する際、正しい整理はどれか。

1. 教材を読了した人は、全職種の作業許可を得た人として記入する。
2. 専門工事業者という会社の立場と、本日の職長・連絡担当という役割を別に調べる。
3. カードが金色なら所属会社を元請、本人を現場監督と記入する。
4. 就業経験が長ければ、本日の連絡体制を知らなくても指示先を担当できる。

### 問8
契約書の一項目が労働基準法の最低基準を下回っていた。教材の原則に照らした説明を選びなさい。

1. 最低基準があるので、すでに約束した有利な条件は当然に引き下げられる。
2. 署名があれば最低基準を下回る部分も常に有効である。
3. 下回る部分は無効となり法定基準に置き換わるが、契約全体が自動消滅するわけではない。
4. 一項目が下回れば、賃金や就業場所を含め契約の全条項が消滅する。

### 問9

1. 事前の金額固定が禁止なので、現実の損害の有無や責任も常に存在しない。
2. 退職後に請求すれば、契約で前もって決めた罰金も必ず有効になる。
3. 違約金の条項には日時や契約文を残す必要がなく、相手の性格だけを記す。
4. 事前に賠償額を固定する禁止の問題と、具体的な損害・責任の問題を別に整理する。

### 問10
架空の会社は20日締め・翌月5日払いである。6月21日から7月20日までの勤務と、7月21日の勤務の整理はどれか。

1. 6月21日から7月20日までの勤務は、締め日当日に全額を受け取ったことになる。
2. 両方とも、7月中に働いた日を含むので全て8月5日分に入る。
3. 7月21日は次の期間なので、勤務の記録自体が不要になる。
4. 前者は8月5日支払分の対象で、後者は同じ計算期間に含めない。

### 問11
休憩を除く実働がちょうど8時間の日について、教材の通常の休憩基準を適用した説明を選びなさい。

1. 休憩と表示した時間なら、荷物対応を命じられ離れられなくても必ず自由な休憩である。
2. 8時間に達した瞬間から、必ず1時間という法定最低になる。
3. 法定の最低休憩は45分以上であり、会社がより長く定めた条件は別に確認する。
4. 休憩込みの拘束が8時間なら、実働を調べずに45分と決める。

### 問12
通常の建設事業で、特別条項の下のある月に時間外70時間・法定休日15時間がある。集計の読み方はどれか。

1. 休日を含む月の合計は85時間で、年の時間外や複数月平均等も別に確認する。
2. 月合計85時間なら、年720時間や複数月平均の確認は不要になる。
3. 月の上限確認は時間外70時間だけで行い、休日15時間は全ての集計から除く。
4. 特別条項があれば、恒常的な忙しさだけで毎月限度超過を続けられる。

### 問13
通常の年休付与で勤続3年6か月の人に今回14日が付与された。この14日の意味を、取得管理と併せて説明したものはどれか。

1. 5日取得の管理では、本人がすでに取った年休日を一切算入できない。
2. 付与日数が増えても、本人の年休請求は会社の事前買い取りで常に消せる。
3. 14日は繰越を全て含んだ残数なので、以前の記録は不要である。
4. 今回の付与数であって残数ではなく、繰越・使用分を分け、年10日以上付与の場合の年5日取得管理も考える。

### 問14
解雇予告の適用除外がない人に、解雇日の20日前に予告し、不足分の手当を支払った。そこから言えることはどれか。

1. 不足する10日分の平均賃金の手当と、解雇理由の合理性等は別の問題である。
2. 不足分の計算はどの人でも月給を30で割れば平均賃金として確定する。
3. 現場が終われば、雇用契約の期間や更新履歴を見る必要はない。
4. 10日分を支払えば、解雇理由が何であっても必ず有効になる。

### 問15
同じ役職の同僚が業務に必要な情報を独占し、一人への説明だけを繰り返し拒む。相談時に優越的関係を考える視点はどれか。

1. 役職が同じなら、優越的関係は絶対に成立しない。
2. 事実確認が終わる前は、窓口に相談すること自体が認められない。
3. 役職の上下だけでなく、相手の情報や協力に依存し抵抗しにくい関係があるかを見る。
4. 声が小さい発言なら、業務との関係や就業環境への影響を調べなくてよい。

### 問16
揚重作業の配置表に「運転」「玉掛け」が分けてある。応募者が「クレーン関係の修了証がある」とだけ話した。適切な読み取りはどれか。

1. 同じ揚重でも担当行為は異なり、機械の種類・能力と証明書の対象業務を対応させる。
2. 教材を読んだ経験は、対象となる法定教育の修了と同じである。
3. 証明書が一枚あれば、現場の合図と本日の配置の確認は終わっている。
4. 同じ揚重なので、どの修了証でも運転と玉掛けの両方を含む。

### 問17
暑い屋内で同僚の返答が普段より遅いと気づいた。現場には飲料水もある。この情報の評価として教材に合うものはどれか。

1. 屋内なら屋外の暑さ対策の対象ではないので、異変の報告も不要である。
2. 屋内や飲料水の存在で危険を除かず、見た変化と場所を定めた報告先へ伝える。
3. 飲料水があることを理由に、他の作業条件を見ず続行可能と判断する。
4. 熱中症という診断名を本人が確定するまで、報告を待つ。

### 問18
新材料の危険について朝礼で発言し、保護具を配布した。リスク低減の検討はこれで全て済んだだろうか。

1. リスクを低いと見積もれば、法令が要求する措置も省略できる。
2. 朝礼で危険を一つ言えば、見積りも対策後の確認も自動的に完了する。
3. 危険の特定に加えて起こりやすさ・被害を見積もり、除去や設備・管理等の措置と残る危険を検討する。
4. 保護具を配れば、危険そのものをなくせるかの検討は一切不要である。

### 問19
最低賃金との比較用に、基本給・職務手当・通勤手当・残業代がある明細を整理する。適切な方法はどれか。

1. 総支給には残業代も入っているので、それを全て比較対象として使う。
2. 通勤手当と時間外分を除き、職務手当の内容を確認した比較対象額を所定時間に対応させる。
3. 税・保険を引いた手取り額だけを時間換算すればよい。
4. 手当という名称の項目は、職務手当も含め全て除く。

### 問20
業務中の事故後、会社から「労働者死傷病報告を出した」と言われた。本人の労災保険について正しい理解を選びなさい。

1. 外国人または短時間勤務なら、雇用された労働者でも当然に対象外である。
2. 会社が証明しない場合は、監督署へ事情を話すこともできない。
3. 事故報告を出せば、本人の全ての給付請求も自動的に完了する。
4. 会社の事故報告と本人の給付請求を分け、証明が得られない場合も事情を説明して監督署へ相談できる。

### 問21
契約上の週所定時間は18時間だが、繁忙期のある週だけ残業を加えて22時間働いた。雇用保険の加入条件を読む際の着眼点はどれか。

1. 給与控除があれば、被保険者証等がなくても届出済みと確定する。
2. 雇用保険は労災保険と同じく、保険料を全て事業主だけが負担する。
3. 一週でも実働20時間を超えれば、所定時間や雇用見込みを見ず加入条件が全て決まる。
4. 一時的な実働ではなく所定時間と雇用見込み等を分け、加入状況は控除だけで断定しない。

### 問22
社内の説明会、認定職業訓練、技能検定の合格を同じ「研修済み」の欄にまとめた。どの訂正が制度の目的を正しく表すか。

1. 社内で仕事を教える活動は、全て知事認定の職業訓練である。
2. 社内説明と知事が認定する訓練、国が技能を証明する検定を分け、技能士と技士も区別する。
3. 技能士と施工管理の技士・技士補は、文字が似るだけで同じ制度である。
4. 技能検定に合格して技能士になれば、同じ等級のCCUSと在留資格へ自動的に変わる。

### 問23
施工資料に「工事監理者」と「監理技術者」がある。名称の似た二者の区別として適切なのはどれか。

1. どちらも職長が班員へ作業連絡する役割の別名である。
2. 名前が似るので、施工体系図では必ず同一人物として記載する。
3. 一式工事の許可を持つ会社では、両者の業務や専門工事区分は全て消える。
4. 設計図書との関係を確認する業務と、建設業法に基づく施工の技術上の管理を分ける。

### 問24
同じ敷地で、建物が占める面積と各階の面積の合計を比べる。建ぺい率・容積率について正しい組合せはどれか。

1. 建ぺい率は敷地に対する建築面積、容積率は敷地に対する延べ面積の割合である。
2. 同じ規模の建物なら道路や地域に関係なく、別敷地と同じ割合を使える。
3. 建ぺい率も容積率も、外壁の表面積を敷地で割る割合である。
4. 建ぺい率は延べ面積、容積率は建築面積を使い、二つの分子を逆にする。

### 問25
産業廃棄物の委託処理で、マニフェストに運搬終了の情報だけが戻った。次の解釈のうち正しいものはどれか。

1. マニフェストは埋立という処分方法だけを指定する書類である。
2. 運搬が終われば、処分・再生も同時に完了した意味になる。
3. 元請が自社運搬し許可不要なら、処理基準も一切守る必要がない。
4. 運搬と処分・再生の終了は別なので、後者の情報まで処理の流れを追う。

### 問26
石綿を含む成形板の工事が、教材でいう14日前届出の対象でないと説明された。その説明から言える範囲はどれか。

1. 調査記録があれば、隔離や保護具等の異なる確認も全て代替できる。
2. その届出の対象外でも、事前調査や該当する作業基準が不要になったとはいえない。
3. 届出が不要なら、材料の含有調査も全て不要になる。
4. 別の部屋の結果があれば、今回の材料も外観だけで非含有と確定できる。

### 問27
住民から「昨日の午前に振動を感じた」と連絡があったが、測定結果は手元にない。受付者の記録として最も適切なのはどれか。

1. 問い合わせが一件あったので、振動規制違反が確定したと記す。
2. 低騒音型の機械なので、振動も含め全く問題なしと記す。
3. 受けた言葉、日時・場所、分かる作業を残し、違反や工法変更・補償を独断で確定しない。

### 問28
改修の引継ぎに「調査記録は受領、範囲との照合は未了。搬出先は回答待ち」とある。このメモの理解として適切なのはどれか。

1. 資料を持つこと、対象を確認すること、手続きを終えることを分けたメモで、開始許可そのものではない。

3. 調査記録を受領したので、対象範囲との照合も完了している。
4. 担当者名が一人なら、調査資格と職長の役割や処理責任も同じ条件になる。

### 問29
コンクリートに接した排水を処理し、pHは適用範囲に入った。この結果の限界を説明した文はどれか。

1. pHさえ適合すれば、SSや金属も全て除去された証明になる。
2. 炭酸ガスを入れた記録だけがあれば、処理後の測定や校正状態は不要である。
3. pH以外のSS・金属等や排水先の条件も別に確認し、pH適合を全汚染物質の除去とはしない。
4. 基準は必ず上限だけなので、全ての項目は低いほど適合する。

### 問30
施設の消防設備を「火災を知らせる」「消火する」「避難を助ける」に分ける。正しい対応はどれか。

1. 警報設備は知らせる側、スプリンクラーは消火側、避難はしごは避難を助ける側である。
2. 消火器が見えれば、建物の用途が変わっても他の必要設備の確認は不要である。
3. 警報設備は水を放出し、避難はしごが火災信号を受ける。
4. 名前を三分類できれば、設備の操作教育も修了したことになる。

### 問31
設備会社の資料に、電気工事士の免状、会社の登録、製品の表示がある。これらの役割を説明したものはどれか。

1. 製品の安全表示は、その製品を使う人全員の電気工事士資格も証明する。
2. 個人の作業資格、事業の登録・規制、対象製品の安全を扱う別の情報である。
3. 会社の登録があれば、設備の技術基準や個別作業の安全確認は不要である。
4. 個人の免状があれば、会社の登録・届出は済んだことになる。

### 問32
技適表示がある別機種のトランシーバーから相手の声が聞こえた。送信に使えるかの説明として適切なのはどれか。

1. 受信できたことだけで、どの周波数でも合法に送信できる。
2. 海外で使えた機器なら、日本では型番や使用条件の確認が不要になる。
3. 技適表示は、全ての無線局免許と登録を一括して取得した証明である。
4. 技適は技術基準の情報であり、無線局の区分や免許・登録、予定用途は別に確認が必要である。

### 問33
クレーンの計画に「地表から60メートル」とある。航空障害灯と昼間障害標識について正しい説明を選びなさい。

1. 機械の長さと地表からの高さは、設置状態にかかわらず必ず同じである。
2. 60メートルちょうどなら、60メートル以上に含まれない。
3. 航空障害灯は原則対象となる高さだが免除等の条件があり、昼間標識や位置の条件も別に扱う。
