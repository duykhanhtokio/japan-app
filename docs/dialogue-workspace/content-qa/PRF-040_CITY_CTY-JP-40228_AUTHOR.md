# 朝倉市 独立執筆記録

教室受付と開始時刻、友人の説明支援と代理手続き、二職場の必要事項、片方のイヤホン、重い荷物と運搬、機械内のカード、瓶と外袋、鳥の写真と歩行範囲という異なる原因で構成。看護師は提出条件や発行を決定せず書類窓口へつなぐ。回収・停止・交換・参加・発見等は確認前に保証しない。
