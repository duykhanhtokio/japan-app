# 南国市・独立執筆記録

担当は CTY-KCH-NANKOKU の八場面のみ。開始案内と AGENTS.md を同一セッションで全文確認済み。自市の入力を参照し、他市の本文を読まずに執筆した。全ての最終前提、八十八発話、四十の行動と目標を読み直して照合した。レンタカーは返却経路を相談する場面、野菜ハウスは担当者から指導を受ける前の確認に限定した。

全場面は架空の会話練習で、訳文や級別制限はない。実在店舗の料金・規約・保証や運転経路を確認済みとはしていない。教室の分類と娯楽施設の役割を整え、広い分類を使う限界は ROLE_ALIGNMENT.json に記した。AI自己確認のみで、人間・母語話者・相互レビューは未実施。件数とハッシュは SELF_REVIEW.json に記録。統合と公開は担当者へ引き継ぐ。
