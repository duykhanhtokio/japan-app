# 飯塚市 独立執筆記録

担当は CTY-FKO-IIZUKA の八場面。各場面は係員六発話と学習者五発話が交互に続く十一発話で、学習者に対応する個別の行動名と目標を五組作成した。最後の係員発話はその場面の区切りと次の行動に合う形にした。

三人への和菓子の購入日、古民家の傘と土間、食品工程間の引継ぎ、遅延時の迎えへの連絡、野球場の入口の相違、果実の色と大きさ、左利きの書道準備、共同注文前のアレルギー確認という異なる事情から話を進めた。野球場を公演の場面として扱わず、球技観戦の入口相談へ改めた。全八場面の最終状況・全発話・全目標を再読した。

他都市の文章を読まず、相互レビューは実施していない。人間・母語話者・第三者のレビューは未実施。日本語のみで翻訳と難易度制限は追加していない。実在施設、モノレールや路面電車、料金、商品の安全性、農作業や衛生手順を確認したとする主張はない。

SELF_REVIEW.json に入力・出力ハッシュと構造・重複確認を記録した。Factory と Classroom の補正、交通窓口の架空名称、野球場分類と表示画像の限界は ROLE_ALIGNMENT.json に記録した。親担当が統合・コミット・遠隔保存確認を行う。
