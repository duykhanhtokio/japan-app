# 新居浜市 独立執筆記録

担当範囲は CTY-EHM-NIIHAMA の八場面のみ。各場面は十一発話、交互の係員六発話と学習者五発話、五つの個別課題で構成した。

図面の改訂待ち、祭り備品の迂回搬入、歯車展示の図による記録、雨天の荷物と帰着時刻、辛さ別の持ち帰り注文、日よけの撤収、三脚持込みの確認待ち、材料未確認による注文辞退という別々の因果関係を執筆した。八場面の状況、発話、目標をすべて再読した。最後に修正した発話も再読した。

他都市の文章は読まず、相互レビューは行っていない。人間・母語話者・第三者の承認は未実施。翻訳と難易度制限は追加していない。実在施設、運行時刻、料金、規則、医学的な安全性の保証はしていない。

入力と出力のハッシュ、構造と重複確認の集計は同接頭辞の SELF_REVIEW.json に記録した。工場の分類補正案と施設名の未確認事項は ROLE_ALIGNMENT.json に記録した。統合・コミット・遠隔保存確認は親担当が実施する。
