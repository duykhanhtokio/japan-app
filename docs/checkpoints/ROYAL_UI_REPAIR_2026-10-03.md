## Findings and implementation

1. Home cards: source images are opaque 2172×724, with no empty right/bottom image margins. Historical `39c52c0f9814200aa3634a08736a7fa3cc93ddc8` used `cardImage.flex: 1`. The reported version instead used `width: '100%', height: '100%'` on a padded ImageBackground (36px horizontal, 11px vertical). Native React Native ImageBackground explicitly reapplies those dimensions to its nested Image; its implementation documents that this conflicts with its internal layout model. Replaced this ambiguous padded sizing with one sibling absolute-fill Image, one flex text overlay and the existing border-only frame. Text padding no longer sizes the artwork. This is a verified source regression and an explicit fix to that sizing dependency; the native screenshot symptom was not reproduced in this Linux environment. Browser before/after components both covered their cards, so browser QA cannot prove the native root cause or native completion.
2. Learn: removed the RoyalNavyFrame around JLPT 学習, retained the help button and used approved royal navy `#142847` for plain title text. Did not touch locked exam-taking UI.
3. Transitions: confirmed map viewport fallback `#173C24`, cow fallback `#79A94D`, chicken fallback `#78A94E` and orchard grass fallback. The navigator was already navy with animation disabled; the map was already retained while entering an area. Replaced scene background rendering with expo-image, memory/disk cache and zero transition. Area entry now waits for expo-image prefetch as well as Asset.loadAsync, and refuses to switch if preload fails. Fallbacks are navy. This removes known green sources and adds image readiness, but does not prove that all reported stutter/flash causes are resolved. Native navigation/video validation is pending.
4. Vocabulary: transparent search field over blurred artwork was the contrast problem; no parent opacity was found in this route. Search now has an opaque light surface, explicit input/placeholder colors and Japanese font. Removed Royal wrappers from word entries and navy example panels; examples use plain readable text. Search scope and word navigation unchanged.
5. Farm HUD: old avatar was 72px wide with only 48px reserved for text, positioned outside normal layout; old player/resource flex weights were unequal and Back consumed row width. Avatar now occupies a normal 48px layout slot, followed by text. Back sits in its own row; the two HUD panels have equal flex and an 8px gap. Visible resource labels are replaced by coin, diamond and key images, while accessibility labels and callbacks remain. Icons are 30px, numeric text 12px. Large resource amounts use K/M display while accessibility retains full amounts. Long EXP fractions reduce font size to fit.
